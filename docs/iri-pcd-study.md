# 用逐像素三维坐标归档实物 T 恤

IRI UPC-CSIC 的 Clothing Part Dataset 发布了 Kinect 彩照、已注册的 640 × 480 XYZ 点云、前景掩码及领口和袖口的人工标注。蓝色 Vespa 印花圆领 T 恤在 `n00700` 和 `n00764` 中有两次近似平铺的正面捕获。两帧按连拍组以及颜色、领型和印花位置相互对应，发布标注没有独立的实物编号字段。公开页面提供下载和论文引用说明。本实验保存数据哈希及聚合指标。[数据发布及引用](http://www.iri.upc.edu/groups/perception/clothingDataset/) · [原始论文](https://doi.org/10.1016/j.patcog.2016.07.003)

模型输入只使用 `n00700` 的几何。程序用原始 XYZ 点云及掩码恢复桌面和毫米正投影，原彩照和点云保留在经哈希校验的档案中。台面拟合残差 P90 为 **4.53 mm**，掩码内有效点覆盖 **100%**。单面模型使用预测和几何测量生成纸样，DXF 回读 **5 片**毫米裁片，记录 **15 条**接缝。GLB 与可编辑 Blender 场景来自同一纸样，并保留 **4 处**成衣开口。

## 留出实物点云

`n00764` 的点云单独拟合其桌面和下摆方向。对照时沿用输入帧推得的袖子摆放角度，两者仅做平移，保留物理尺度。以下为 **110,386** 个留出布面点的结果。[捕获与评测哈希](iri-pcd-study.json)

| 指标 | 结果 |
| --- | ---: |
| 平铺轮廓交并比 | 82.72% |
| 轮廓边缘距离 P90 | 70.43 mm |
| 留出可见点到同版平铺模型 P90 | 8.86 mm |
| 预测减实测外包围宽、高 | −7.37 mm、+33.59 mm |
| 留出点离各自布面中值高度 P95 | 10.29 mm |

两次采集的袖子、下摆褶皱和铺开程度有差别。薄布在两次采集中都贴近桌面，点到面距离主要反映覆盖区域的高度。较大的轮廓距离显示袖口或衣摆偏差，影响仍需用统一姿态和实物量尺区分。本实验覆盖已注册点云定尺度、平铺可见布面和 DXF 完整性。蓝色款的背照、净版片、裁缝尺量值和独立挂拍仍待补齐。

## 复现

```sh
python -m examples.evaluate_iri_tee -o build/iri-tee
python -m superarchiveallclo.check_archive build/iri-tee/registered/archive
```

脚本从原始 ZIP 中下载并校验两帧图像、点云和掩码，避免下载全档。原始文件存入 `source/`，归档存入 `registered/archive/`，留出评测和实际用于评分的平铺 GLB 存入 `comparison/`。正背齐全的馆藏样本仍可走同一项目的照片入口。[馆藏尺寸盲测](paired-photo-study.md) · [正背印花实验](photo-appearance-study.md)
