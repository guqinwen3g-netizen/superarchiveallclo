# 用逐像素三维坐标归档实物 T 恤

IRI UPC-CSIC 的 Clothing Part Dataset 发布了 Kinect 彩照、已注册的 640 × 480 XYZ 点云、前景掩码及领口和袖口的人工标注。蓝色 Vespa 印花圆领 T 恤在 `n00700` 和 `n00764` 中有两次近似平铺的正面捕获。两帧按连拍组以及颜色、领型和印花位置相互对应，发布标注没有独立的实物编号字段。公开页面提供下载和论文引用说明。本实验保存数据哈希及聚合指标。[数据发布及引用](http://www.iri.upc.edu/groups/perception/clothingDataset/) · [原始论文](https://doi.org/10.1016/j.patcog.2016.07.003)

模型输入只使用 `n00700` 的几何。程序用原始 XYZ 点云及掩码恢复桌面和毫米正投影，原彩照和点云保留在经哈希校验的档案中。台面拟合残差 P90 为 **4.53 mm**，掩码内有效点覆盖 **100%**。单面模型使用预测和几何测量生成纸样，DXF 回读 **5 片**毫米裁片，记录 **15 条**接缝。GLB 与可编辑 Blender 场景来自同一纸样，并保留 **4 处**成衣开口。

## 留出实物点云

`n00764` 的点云单独拟合其桌面和下摆方向。对照时沿用输入帧推得的袖子摆放角度，两者仅做平移，保留物理尺度。以下为 **110,386** 个留出布面点的结果。[捕获与评测哈希](iri-pcd-study.json)

| 指标 | 结果 |
| --- | ---: |
| 平铺轮廓交并比 | 82.72% |
| 轮廓边缘距离 P90 | 70.43 mm |
| 留出可见点到同版平铺模型 P90 | 8.86 mm |
| 预测减实测外包围宽、高 | −7.37 mm、+33.59 mm |
| 留出点离各自布面中值高度 P95 | 10.29 mm |

两次采集的袖子、下摆褶皱和铺开程度有差别。薄布在两次采集中都贴近桌面，点到面距离主要反映覆盖区域的高度。较大的轮廓距离显示袖口或衣摆偏差，影响仍需用统一姿态和实物量尺区分。本实验覆盖已注册点云定尺度、平铺可见布面和 DXF 完整性。蓝色款的背照、净版片、裁缝尺量值和独立挂拍仍待补齐。

## 台面内自动摆正

逐张检查了这一组的 51 个 T 恤部件标注帧。找到两张完整展开、在图像内明显旋转的正面，`n00634` 与 `n00647`。未看到可用于背片制板的完整平铺背面。两次实拍分别估计出 **62°** 和 **−85.5°**，程序在拟合桌面以后刚性旋转三维坐标，再复用原制板及求解流程。没有参与制板的 `n00764` 继续作为复扫对照。已接近正放的 `n00700` 估计偏转 2°，保持原投影。明显折叠的 `n00697`、`n00748` 和裁切过的红色 `n00320` 均被可选的自动摆正入口拒绝。

| 单面候选纸样 | 原胸宽 | 摆正后胸宽 | 原后中衣长 | 摆正后后中衣长 |
| --- | ---: | ---: | ---: | ---: |
| `n00634` | 713 mm | 484 mm | 701.61 mm | 669.61 mm |
| `n00647` | 666 mm | 478 mm | 619.61 mm | 675.61 mm |

同件两次大角度采集的胸宽预测差从 47 mm 缩至 6 mm，后中衣长差从 82 mm 缩至 6 mm。两份摆正结果通过同版 DXF 与 GLB 回读。袖长预测仍相差 100.25 mm。两张摆放时袖子展开程度不同，程序从两张识别到的袖口或腋下证据也不同。这些数值衡量复扫一致性。该公开序列没有独立卷尺胸宽或纸样可用于对应评分。

| 与同一留出扫描比较 | 轮廓交并比 | 轮廓距离 P90 | 可见点到模型 P90 |
| --- | ---: | ---: | ---: |
| `n00647` 原坐标制板 | 75.46% | 109.04 mm | 10.28 mm |
| `n00647` 摆正后制板 | 73.39% | 70.00 mm | 19.99 mm |
| `n00634` 摆正后制板 | 78.35% | 66.75 mm | 14.37 mm |

`n00647` 摆正后，轮廓距离 P90 缩小，整体重合度下降，点到面偏差扩大。候选模型平铺外宽比留出参考少 120.67 mm，袖长与袖子的摆放仍是明显误差来源。[各配置归档和扫描哈希](iri-pcd-study.json)

将 `n00700` 和 `n00764` 的实测布面各自水平校正，用同一比较程序度量两次实拍本身的轮廓差，得到 **90.02%** 的交并比和 **40.45 mm** 的轮廓 P90。这个实物复扫基线和模型误差采用同一 2 mm 网格与对齐规则。

## 复现

```sh
python -m examples.evaluate_iri_tee -o build/iri-tee
python -m superarchiveallclo.check_archive build/iri-tee/registered/archive
python -m examples.evaluate_iri_tee --input-frame n00634 --auto-upright -o build/iri-tee-upright-634
python -m examples.evaluate_iri_tee --input-frame n00647 --auto-upright -o build/iri-tee-upright-647
```

脚本从原始 ZIP 中下载并校验两帧图像、点云和掩码，避免下载全档。原始文件存入 `source/`，归档存入 `registered/archive/`，留出评测和实际用于评分的平铺 GLB 存入 `comparison/`。默认帧额外输出实拍复扫之间的 `repeat-capture.json` 及叠图。省略 `--auto-upright` 可按原台面坐标生成对照结果。正背齐全的馆藏样本仍可走同一项目的照片入口。[馆藏尺寸盲测](paired-photo-study.md) · [正背印花实验](photo-appearance-study.md)
