# 产品与首款设计

## 产品要回答的问题

给定一件参考服装或一个新设计，能否做出目标轮廓，能否把它拆成可以裁剪缝制的衣片，同一件衣服换到另一种体型上又会怎样？一次交付应包含同一版次的二维纸样、缝合与用料说明、三维仿真、试穿结果和仍需确认的事项。设计师能从草图创作，个人开发者也能用自己拍摄的一件衣服开始。

## 第一套 Clean Fit 男装

已确定的方向是极简男装穿搭。下列单品与顺序是首版设计提议，目的是在少量款式上把比例和合体做准。

| 单品 | 设计意图 | 模型需要控制的量 |
| --- | --- | --- |
| 微落肩圆领 T 恤 | 衣身宽松，肩线稍下移，袖口与下摆有明确落点 | 人体净胸围、成衣胸围及二者之差，落肩量、袖肥、衣长、领口尺寸、领条回缩 |
| 无褶直筒长裤 | 裤腿从大腿到脚口保持接近直线，裤脚在鞋面形成预期的堆量 | 腰臀松量、前后裆、内长、膝围、脚口围，裤腰、门襟及口袋结构 |
| 无里布外搭衬衫 | T 恤外多一层后，肩袖仍有活动空间 | 内外层胸围差、袖窿深、叠穿次序、下摆高差、层间接触 |

用正面、侧面和背面查看同一套搭配。在同一人体和姿势上只改变一个变量，例如把 T 恤衣长缩短 20 mm，就能比较下摆和裤腰的位置，同时检查纸样和尺寸表是否一起改变。配色与纹理可替换，版型比例保留为可测量的设计变量。

## 从不同证据开始

| 输入 | 能直接利用的信息 | 还需要解决的信息 |
| --- | --- | --- |
| 真实平铺、挂拍或穿搭照片 | 可见轮廓、衣长比例、局部缝线、多视图之间的对应；穿搭照可先选中某件衣服 | 单张正面图可能同时符合多种后片或肩缝结构。没有尺度时先给候选版，可补一个按指引实测的成衣尺寸或带参照物的照片 |
| 手绘设计图 | 廓形意图、细节标注、理想比例，可从夸张的草图提出不同结构解法 | 由设计者选择希望保留的轮廓和目标松量，结合号型或目标成衣规格定尺寸 |
| 正背技术图、尺寸表 | 部件、明线、测量部位与带单位的数值；同款正背图可一起输入 | 图纸比例、平量与整圈、净体与成衣尺寸分开记录。缺少的工艺细节允许编辑 |
| 3D 服装扫描、点云或网格 | 有标定时可利用表面几何、视角、比例和垂感；记录平铺、挂置或着装状态 | 穿着状态已包含布料形变。保留遮挡和孔洞标记，内层、缝份及材料参数仍需推断或补充 |

每种输入都能单独开始。补图、附面料标签、输入尺寸或加入第二种模态时，用户可以看到哪些推断随证据改变；已确认的设计参数可以锁定。

## 一次实际使用

1. 上传一张 T 恤正面照，选中目标单品。系统标出可见肩点、袖口和下摆，并说明当前对后领及领条结构的假设。
2. 用户输入按指引平量的半胸宽。如果只想探索造型，也可以选一个参考人体和目标成衣尺寸，记录这些值的来源。
3. 系统给出候选纸样和配套的三维外观。用户可锁定胸围、调整落肩量，或选择不同袖型；每次修改都会生成可追溯的新版本。
4. 在基准人体上检查衣长和垂感，再换到不同尺寸的人体，用相同面料和姿势比较肩线、松量及袖口落点。穿搭模式中再加入裤装和外套。
5. 导出纸样、尺寸表、缝合表、材料配置、三维预览与校验报告。交付界面同时显示哪些部分来自观察、实测、用户选择或模型推断。

## 怎么称呼交付物

| 交付状态 | 可以做什么 | 需要的证据 |
| --- | --- | --- |
| 候选版 | 编辑结构，比较轮廓、尺码和不确定项 | 裁片与缝合关系可读，推断和假设有记录 |
| 可打样版 | 按 1∶1 输出裁片，在指定面料条件下试裁试缝 | 关键尺寸有依据，裁片闭合，缝线、缝份、布纹、剪口、裁片数量、裁剪方式和工艺信息齐全，导出后复核比例与配缝 |
| 实样已验证 | 复现某款、某码、某面料的样衣 | 记录实物测量、试穿观察、修版差异以及通过的具体版本 |
| 生产交付版 | 在已验证的目标 CAD 与生产流程中交付该款 | 目标 CAD 回读与打样记录齐全。按交付范围核对放码、工艺公差、材料和尺码覆盖，附版次及验证范围 |

首个可演示目标是一件真实 T 恤的候选纸样和同版次试穿。生产级是需要用实物和目标 CAD 证明的后续能力。首轮开发可以由一个人完成。
